## What was cut

- **Fonts.** A census of 24 routes at 1440 EN and 390 ES, using `document.fonts` with status `loaded`, found that **no italic face, no IBM Plex Mono 300 and no Playfair 900 loads on any page**, so all three are dropped, along with the vietnamese and `*-ext` script subsets. **Inter and JetBrains Mono are not dead.** Inter is the root `font-sans`, and JetBrains Mono is `font-mono`, used on 2,213 class sites and the most-rendered face. Both stay at the weights the census saw. Each family is served as the same Google woff2 files and unicode-ranges as before (24 files, 612 KB on disk; a page loads 3–7 of them) with OFL licences beside them. Two faces are preloaded: EB Garamond latin and Plex Mono 400. Metric-matched local fallbacks were added for Inter, Playfair and both monos.
- **First-load JS.** `EntityProfileDrawer`, which is mounted on every page, statically pulled `EditorialSparkline`, and through it all of recharts. The drawer now mounts on first open. The six recharts primitives in the editorial barrel are now `lazyChart` wrappers whose fallback is an empty box of the chart's own height: `EditorialLineChart`, `AreaChart`, `ScatterChart`, `ComposedChart`, `Sparkline` and `RadarChart`. Callers are unchanged. The Atlas engine's d3 modules (`d3-selection`, `-zoom`, `-quadtree` and the deps of `d3-zoom`) now have their own chunk. `d3-sankey` had no importer. The shell's `story-content.ts` import (417 KB of chapter text, used for 12 headlines) became `lib/story-index.ts` (13.5 KB). A test pins it to `STORIES`.
- **CLS.** On a phone, `PhoneAtlas` showed a one-line loading state, which let the site footer rise into view and drop back down; the loading state now holds `100svh`. On `/dashboard`, three things shifted the masthead: the edition line's contract count wrapped the line at 412 px when it arrived, the dek appeared late, and the lede's «—» placeholders re-wrapped the paragraph. Each now holds its final room through `.mh-held`, which paints a `data-hold` string from `::before` with `visibility: hidden`. No placeholder figure enters the text or the accessibility tree; `PageMasthead.test` enforces this.

## What remains

- **Mobile TBT did not reach ≤ 600 ms on `/dashboard`, `/sectors` and `/vendors`** (final: 1,405 / 969 / 1,597 ms). CPU profiles taken at 4× throttle with sourcemaps (`perf/profile-*.txt`) show where the time goes:
  - React rendering the whole page: react-dom self time 550–870 ms.
  - Style and layout of the full DOM: 2.8 s of "(program)" on `/vendors`, and the ResizeObserver pass on `/sectors` (590 ms) that `useMeasuredWidth` figures trigger.

  The next lever is mounting below-the-fold dossier sections on intersection, with reserved heights. `content-visibility: auto` was **not** applied, because its paint containment would clip overflowing decorations and anchor overlays, and would re-parent fixed descendants: a visual-voice risk.
- **i18n in the shell.** Both languages' locale JSON (≈ 440 KB unminified) is still in the main bundle. Loading only the active language makes first render wait on one more fetch. That is a tradeoff for the lead, not a free win.
- **Mobile LCP** is still 5.4–8.7 s locally, because the pages are client-rendered and wait on API data. Only prerendering or SSR of the masthead would move it substantially.
- **Prod checks after deploy.** Run `curl -I` on `/assets/*`, `/fonts/*`, `/og/*` and `/sitemap.xml`; the preview cannot show nginx headers. They were verified on a local nginx 1.26.2 (`perf/nginx-headers.txt`).
- **Noticed, not changed.** nginx's server-level `Content-Security-Policy` and `X-Frame-Options` never reach HTML responses. Any `add_header` inside a location block drops the inherited ones, and SPA routes end in `location = /index.html`. Prod HTML today carries only Caddy's headers.
