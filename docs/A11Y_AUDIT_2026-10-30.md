## What changed

- **2.5.3 Label in Name.** Overriding `aria-label`s that did not contain the visible text were removed and the extra
  context moved into `sr-only` text after the visible text (name now = visible text + context):
  `TopBar` (brand, search + `aria-keyshortcuts`), `DrillToggle` (`dossier/layers.tsx`, every dossier L3 drill),
  `FocosWall` cards (label only), `CasesBand` rows, `CategoryCover` rows, `ContractsLadder` rungs.
  `EntityIdentityChip` (`variant="name"`) now prefixes an override label with the visible text when it is missing
  (fixes «IMSS» links read as «Instituto Mexicano…» everywhere, incl. Captura and El tablero). `ElTablero` plain links: same.
- **1.4.3 Contrast.** Coloured type now goes through the existing `textInk()` twin from `@/lib/constants`:
  `NoSeVe` / `Captura` claim figures (teal #0f9f8a → #115e59), `BalanzaLedger` phone ledger (amber #d97706 → #b45309),
  `Relevo` sector keys. `GradeAnatomy` cut labels inherited `opacity .45` from their tick line; the opacity now lives
  only on the line (`color-mix`).
- **4.1.2.** `role="img"` → `role="group"` on two SVG charts that contain focusable controls
  (`VendorCommandPanel` trend, `noSeVe/Cinta`), so the controls stay announced.
- **2.1.1.** Overflowing table wrappers made keyboard-scrollable (`tabIndex=0`, `role="region"`, bilingual label):
  5 in `Methodology`, 1 in `FocosRojosMethod`, 1 in `Datos`.
- **1.3.1.** `VendorExpediente` «El mayor del año» caption moved out of the `<dl>`; headings that skipped a level
  get `aria-level` (InstitutionDossier cover, CaseBand side, Rastro cards) — no visual change.
- **2.5.8.** `Relevo` sector keys staggered 24 px (was 22). Pin labels in El tablero and the two cover links on the
  institution dossier get a 24 px box (`py-1 -my-1`, layout unchanged).
