## How to find things fast

1. **Outline before reading.** `smart_outline(file_path=…)` (claude-mem) gives a file's skeleton for ~1–2K
   tokens; `smart_unfold(file_path, symbol_name)` pulls one function; `smart_search(query, path="frontend/src")`
   finds symbols across a tree. Read whole files only when < ~300 lines or non-code.
2. **Route → page:** `grep -n 'path="captura"' -A8 frontend/src/App.tsx` — the element is the page component.
3. **Page numbers / nav:** `frontend/src/lib/nav/toc.ts` (`TOC`, `OFF_NAV`, `folioFor`, `numeralOf`). Never type a numeral.
4. **Page → endpoints:** `grep -oE "[a-zA-Z]+Api\.[a-zA-Z]+" frontend/src/pages/X.tsx | sort -u`, then
   `grep -n "getFoo" -A3 frontend/src/api/client.ts` for the URL. Hooks with many calls: `hooks/useVendorData.ts`,
   `hooks/useExecutiveData.ts`, `api/entityQueries.ts`.
5. **Endpoint → handler:** router prefixes: `grep -HoE 'APIRouter\(prefix="[^"]+"' backend/api/routers/*.py`;
   then `grep -n '@router.get("/summary' backend/api/routers/categories.py`. `analysis.py` has a line index:
   `backend/api/ROUTER_MAP.md`.
6. **Page → components:** `grep -oE "from '@/components/[^']+'" frontend/src/pages/X.tsx`.
7. **Strings:** `grep -rn '"key"' frontend/src/i18n/locales/es/` (namespaced JSON) or inline `lang === 'en' ? … : …`.
8. **Table → writer:** `grep -ln "CREATE TABLE.*<table>\|INTO <table>" backend/scripts/*.py`; schema in `docs/TABLES.md`, `docs/DATABASE_SCHEMA.md`.
