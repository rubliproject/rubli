## 4. `label_tier`

New TEXT column on `ground_truth_vendors` (the link that training expands) and `ground_truth_contracts` (the contract rows). Recomputed on every run.

«Independent source» = case `provenance_tier IN ('A','B')` and not `exclude_from_training`. «Scoped» = case names its buyer(s) (`fraud_institution_ids` or `ground_truth_institutions`).

| Tier | `ground_truth_contracts` | `ground_truth_vendors` (link) | local copy (contracts / links) |
|---|---|---|---|
| A | `evidence_tier = 'direct'`: an external source names this contract (the 8 L4 pilot rows: Oceanografía ×6, COVID ×1, Tren Maya ×1) | — | 8 / — |
| B | independent source **and** contract at a buyer the case names **and** inside the case window | independent source **and** scoped case | 1,861 / 46 |
| C | independent source, any other contract | independent source, unscoped | 44,289 / 164 |
| D | no independent source (model-only, ARIA self-citation, generic, excluded) — including the `L1_audit_attested` stubs of `gt_phase_b_*` on such cases | same | 258,880 / 1,258 |
| NULL | — | false-positive link | — / 171 |

Training positives today by link tier (after fixes 1–3, `_v09` path): D 196,258 · C 69,791 · B 206 (A contracts are not reachable through a link tier; they sit in the gold hold-out).

### How training would use it (not wired; training code untouched)

1. In `positives()` / `v91_frame`, carry `label_tier` from the link, then upgrade per contract: A if `(case_id, contract_id)` is a tier-A `ground_truth_contracts` row; B if the contract's institution is in the case scope.
2. Weight A 1.0 · B 0.8 · C 0.4; **D quarantined** (or ≤ 0.15, the old T3 cap). Drop links whose case has `exclude_from_training = 1`.
3. Validate on A+B only; report forward-chain AUC per tier and size-controlled (audit § 6.1).
4. Pre-register first: c_pu is fitted as «share of positives labelled», so dropping D (~73 % of positives) will move c_pu and may break the scorer guard `c_pu > 0.30` (audit § 6.3). Re-justify the guard; do not keep D to pass it.

## 5. GT sync (local → prod)

**Source of truth: local `RUBLI_NORMALIZED.db`.** All GT curation (FP reviews, re-links, windows, evidence mining, these fixes) happens there; the deploy DB is built once and no step ships later GT edits (memory `gotcha_prod_gt_drift`). `gt_sync.py` diffs the five `ground_truth_*` tables by primary key over shared columns, prints insert / update / target-only counts and which columns changed.
