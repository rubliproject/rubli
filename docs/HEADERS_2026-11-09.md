# Page heads — inventory and gate (2026-11-09)

Owner, 11-09, after /captura and /gasto-a-ciegas: «the fucking headers again and again and again».
Cause: one head component exists (`frontend/src/components/kit/PageHead.tsx`: crumbs row → kicker → h1 = the finding →
question → optional three lines → toolbar; spacing in `pagehead.css`), but pages built their own heads and drifted.

**Rule:** every routed page opens with `kit/PageHead` (directly, or through `PfShell`). One crumbs row, one h1 (the page's
existing finding), the question line, then the first content object. No second title block, no side box in the head.
A page tour (`PageQuestion`) rides the crumbs row as `<PageQuestion bare … />` («Cómo leer esto ▸») in PageHead `actions`.

**Gate:** `MSYS_NO_PATHCONV=1 PROOF_BASE=http://127.0.0.1:3009 npm run proof:head [-- /route]` (dev server up).
Fails on NO-HEAD · ABOVE · H1 · TITLE · EDGE · SIZE (definitions at the top of `frontend/scripts/proof-head.mjs`), at 1440 and 390.
